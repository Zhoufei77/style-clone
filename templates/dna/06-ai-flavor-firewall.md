# 06-AI 味防火墙（作者专属 · 指令化）

> **这是让下游写不出 AI 味的核心产物。** 前面的 DNA 是"描述作者长什么样"，这份是"把描述翻译成下游能直接执行的硬指令 + 禁令 + 自检"。
> 铁律：**任何一条只有数值、没有指令的规则，等于没蒸。** 数值必须落成"写作时该怎么做/不做"。
> 填写方法见 `references/human-texture-spec.md`、`references/ai-flavor-firewall-spec.md`。

---

## A. 硬禁用清单（作者从不/极少用 → 下游禁用）

> 对照 `distill_metrics.py` 的基线：作者自然密度接近 0 的高危词句，列为**红线禁用**；作者偶尔用的，标注**每篇上限**。下游写完命中红线 = 必删。

### A1. 禁用词（红线，一个都不许出现）
- 待填（从下面清单里挑出"作者基线≈0"的，如：值得注意的是、综上所述、总而言之、与此同时、赋能、抓手、闭环、底层逻辑、未来已来、值得我们深思…）

### A2. 限流词（作者偶尔用，注明每篇上限）
- 「不是A而是B」：每篇 ≤ __ 次（作者基线 __/千字）
- 破折号插入语：每篇 ≤ __ 次
- 排比三连：每篇 ≤ __ 次
- 首先/其次/最后：__（作者用不用？不用就进 A1）

### A3. 禁用句法（结构性 AI 味）
- ❌ 每段"总起句→展开→小结句"的完成闭环（作者是否敢不收尾？照作者来）
- ❌ 结尾空洞升华（「未来已来 / 值得深思 / 让我们一起…」）——作者怎么收尾见 D
- ❌ 名词化翻译腔（进行了/使得/得以/的存在/被…）——作者动词前置，见 C3

## B. 数值 → 硬指令（把基线翻成能执行的动作）

> 左边是脚本给的基线，右边是下游写作时**必须照做**的指令。只有右边这列才真正压 AI 味。

| 基线指标 | 作者值 | → 下游硬指令 |
| - | - | - |
| 句长变异系数 CV | __ | 别让句子一样长。**每 3–4 句里必须有 1 句 ≤8 字的短句/断句**砸下来 |
| 短句(≤8字)占比 | __% | 全文 ≤8 字短句不少于 __ 句；开头 100 字内至少 1 句 |
| 语气词收尾率 | __% | 每 __ 句允许 1 句用 啊/吧/呗/嘛 收尾（作者常用哪个见 C4） |
| 高危词自然密度 | __/千字 | 全文高危词总数 ≤ __ 个（超了就是 AI 味） |
| 名词化密度 | __/千字 | 见到"进行了/使得/的存在"就改成动词直说 |
| 数字/具体度 | __/千字 | 每 __ 段至少 1 个具体名字或数字，不许用"很多/一些/某种" |
| 平均段落字数 | __ | 每段 ≤ __ 字；该短的地方敢一句一段 |

> 填表时把 `__` 换成由作者基线推出的具体数字。指令要具体到"每 N 句/每段/全文 ≤ X"，下游才拦得住。

## C. 作者的"反 AI"招式库（他用什么替代 AI 默认动作，附原文样本）

> AI 味的本质是"用了 AI 的默认动作"。这一节蒸的是作者**每个位置上的替代动作**，配原文样本，下游照着仿。

### C1. 过渡：作者不用 signpost，用什么？
AI 靠"然而/因此/与此同时"硬拽。作者靠——
- 手法：待填（语义顺承 / 短句并置 / 一个反问 / 直接开讲）
- 样本（原文照抄 3–5 处过渡）：
  1. 待填
  2. 待填

### C2. 举证/展开：作者怎么从观点滑到证据？
- 手法：待填（"我认识一个…" / "举个例子" / 直接甩数字 / 讲个场景）
- 样本 3–5 处：待填

### C3. 动词前置：作者怎么说人话（对抗名词化）
- 样本对照（作者原句 vs 可能的 AI 名词化写法）：
  - 作者：「__」　←→　AI 会写成：「进行了…的优化」
  - （3–5 组）

### C4. 语气/态度：作者在哪注入脾气？
- 常用语气词：待填（啊/吧/呗/嘛/哈…）
- 吐槽/自嘲词：待填（离谱 / 说真的 / 我不理解…）
- 样本 3–5 句（带脾气的原文）：待填

## D. 即用型 AI 味自检清单（交付给下游，写完逐条过）

> 这份清单是 DNA 的一部分，下游每写完一篇照着自检。命中即改。

- [ ] 通读一遍：像"人随口说的"还是"报告体"？报告体 = 不合格
- [ ] A1 红线禁用词：0 命中？（然而/因此/综上/赋能/未来已来…）
- [ ] A2 限流词都没超每篇上限？
- [ ] 有没有做到"每 3–4 句有个短句砸一下"？（对照 B 表）
- [ ] 有没有一句一段的停顿？还是每段都四平八稳？
- [ ] 具体度够吗——有没有真名字、真数字、真场景，而不是"很多/一些"？
- [ ] 有没有作者式的语气/脾气（C4）？还是全程中性礼貌？
- [ ] 结尾是作者的收法（见 02 结尾库）还是空洞升华？
- [ ] 排比三连、"不是A而是B"没泛滥？
- [ ] 没有"进行了/使得/的存在"这类名词化翻译腔？

> 全过关，才算"像人 + 像这个作者"。任何一条不过，回去改，别放行。
