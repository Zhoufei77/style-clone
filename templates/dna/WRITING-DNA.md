# WRITING-DNA（整合入口 · 模板）

> 把本文件连同 `01~06` 一起，从 `templates/dna/` 复制到 `<作者名>/` 后填写。
> 这是给下游（人或 AI）的一页纸导航，**≤ 2000 字**，长了说明没蒸干净。

## 作者是谁
- 一句话人设：待填（如「热情但不谄媚的数码导购朋友」）

## 语料与可靠度
- 蒸馏篇数 / 类型覆盖 / 是否达到「可靠级」（≥5 篇）还是「演示级」

## 结构原型（3–5 个）
- 原型 P1：名字 + 一句话节拍序列（见 02）
- 原型 P2：……
- 选题→结构决策树：什么选题用哪个原型

## 语言指纹（5 条）
1. 待填（节奏：句长区间、短句占比）
2. 待填（过渡：作者用什么替代 signpost）
3. 待填（语气：夸张词 / 填充词 / 语气词收尾率）
4. 待填（修辞：类比 / 拟人化命名 / 参数→体验 等）
5. 待填（口头禅 / 固定句式）

## 人味量化基线（关键 6 个数，来自脚本）
| 指标 | 基线 |
| - | - |
| 平均句长 | 待填 |
| 短句(≤8字)占比 | 待填 |
| 语气词收尾率 | 待填 |
| 高危词自然密度 | 待填 |
| 名词化密度 | 待填 |
| 数字/具体度密度 | 待填 |

## AI 味防火墙要点（全文见 06）
- 红线禁用：待填
- 限流词 + 上限：待填
- 硬指令：每 3–4 句 1 句 ≤8 字、全文高危词 ≤N 个、每段/每款 ≥N 个真数字…

## 取用顺序
1. 读 02 拿骨架 → 2. 读 01 样本库学语感 → 3. 对照 06 禁令+指令 → 4. 去重看 05 → 5. 写完过 06 自检。
