# 03 排版 DNA

> 运行时模板。适用于可观察的图文、网页、文档等形式，不预设平台。必须从原 HTML、Markdown、截图或用户提供的结构记录中读取；清洗语料只用于语言分析。缺少信息时标“无法观察”。

## 观察条件

- 匿名样本 ID 与原件定位：待填
- 载体、视口/页面条件与观察时间：待填
- 是否为原始排版、转存或二次排版：待填
- 可观察项与缺失项：样本不足
- 目标发布环境及需要适配的差异：待填
