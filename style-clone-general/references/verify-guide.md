# 比较原样本与新稿

复核回答“哪些风格手法贴近，哪些偏离，以及这些差异是否影响本次任务”。它不鉴定作者身份，不检测 AI，也不保证质量或无侵权。

## 复核方式

工具支持时，可让未参与起草的代理复核。只提供获准样本或相对定位、新稿、本次任务约束和维度清单，不提供起草方法、预期结论或夸奖性描述。预先说明有意更换的身份、自称、文体或发布环境，避免当成错误。

代理读取文件或外部服务接收材料都受原有权限约束。不能因“独立复核”把私密语料上传到用户未授权的服务。不支持代理时，在当前对话中完成同样检查，并明确标记“自检”；不能声称已做独立复核。独立代理也可能有偏差，属于另一份判断。

有条件时用未参与提炼的同组样本补充比较，并记录范围；没有留出样本时说明限制。不得仅凭篇数或一次试写宣称档案可靠。

## 维度与证据

按档案中有证据、且本次任务相关的维度比较。不要向任何题材预设逐款产品、优缺点、参数转体验或固定收口。

| 范围 | 检查内容 |
| --- | --- |
| 节奏与结构 | 句长变化、段落功能、开头、过渡、结尾与节拍顺序；结构适用性是否匹配 |
| 词汇与语气 | 用词档位、术语处理、动词、修饰、代词、常用表达、置信度、幽默、情绪、读者关系和正式度 |
| 修辞与机制 | 类比、举证、重复、提问、标点、强调；可观察时再比较排版 |
| 视角与内容边界 | 思考与取材方式是否迁移；具体经历、身份、案例、数据和标志性表达是否误带入 |
| 本次任务 | 新材料是否成立，稿件是否适合读者，差异是否来自用户有意调整 |

每条发现给出“参考样本位置→新稿位置→差异及影响”。优先用匿名 ID、段落或节拍定位和概述；确需引用时，只用权限允许的最小摘录。未读到原件、排版缺失或样本不足的维度标“无法判断”，不凭印象补证据。

可用同一统计口径补充句长等比较，但统计接近不等于风格接近，差异也不自动等于缺陷。不用总分制造精确感；样本未出现某词、某标点，不能据此判新稿违规。

## 输出格式

```text
方式：独立代理复核 / 自检
范围：匿名样本 ID、文体与处理口径；缺失项
判断：较贴近 / 部分贴近 / 明显偏离 / 证据不足
关键证据：逐项定位、差异、影响
内容边界：是否误用身份、独特内容或未核实事实
修改建议：按影响排序；区分必要修复与可选风格调整
局限：未做的检查与仍无法判断的部分
```

不必凑固定证据条数。用户只要稿件时，复核记录可留在内部，必要问题须简述；要求报告时如实交付。需要保存才写入用户工作区，原样本与摘录不随报告自动公开。

改稿后复查受影响的维度，保留仍然存在的分歧。不能把复核结论润色为“完全复刻”，也不为机械接近指标反复改坏稿件。
