# 语料预处理

清洗的目的是减少格式脚手架对分析的干扰。原件不变，另存分析副本；预处理结果不能证明材料权利、作者归属或文字正确。

## 输入与命令

支持文件或目录，显式指定模式可避免自动识别误差：

```bash
python3 "<skill-dir>/scripts/preprocess.py" "inputs/sample.md" "inputs/more-samples" --out "style-profile/corpus" --mode auto
```

模式为 `auto|transcript|markdown|html|plain`。在用户工作区执行，`<skill-dir>` 替换为本 Skill 的安装位置；输入输出使用工作区相对路径。只有用户希望保存分析副本时才运行写文件命令；不将用户材料写进 Skill 或公开包。

默认保留原标点。需要口播意群分析时，单独生成一份副本：

```bash
python3 "<skill-dir>/scripts/preprocess.py" "inputs/transcript.txt" --out "style-profile/speech-units" --mode transcript --speech-units
```

意群切分会改变统计单位，记录该选项，并与自然句统计分开。输出前确认目录用于本次分析，不覆盖原件或混入旧语料。

## 按材料类型处理

| 类型 | 分析副本的处理 | 原件额外保留的信息 |
| --- | --- | --- |
| 转录稿 | 识别说话人、时间戳、平台标题等脚手架；只分析目标说话者时先确认归属；口头重复和停顿有风格作用时保留 | 时间轴、说话人边界、转写错误与人工修正记录 |
| HTML | 去脚本、样式及标签脚手架，抽取正文与可读段落；检查是否混入导航或页脚 | 标题层级、加粗、引用框、图片及其位置、链接等可观察结构 |
| Markdown | 去除用于统计的标题/引用等标记，保留内容和可辨识段落；代码、表格是否纳入分析须统一口径 | 原始标题、列表、引用、强调、代码与图文位置 |
| 纯文本 | 统一编码和多余空行；不要为“自然”而改写词语、标点或断句 | 原始换行及其来源；纯文本未呈现的排版标为无法观察 |

自动清洗只完成可识别的处理，不保证正确区分正文、引用与多说话人。抽查至少不同来源类型的输入输出；不清楚的内容保留并标记，不能偷偷改成自己认为应有的句子。

## 两条分析路径

**语言路径**读取清洗副本，统计句长、用词、标点等，并记录切分口径。转录错误、合并说话人和人为改标点都可能改变结果。

**排版路径**读取原 HTML、Markdown、截图或用户提供的版式说明。03-layout-dna.md 中的加粗、首屏和图文位置不能靠清洗后的纯文本猜测；缺少原件就填“无法观察”。

## 记录与隐私

来源索引用匿名样本 ID 和相对定位，记录输入类型、处理模式、意群选项、纳入/排除范围和发现的问题。没有权限保存全文时，使用用户指定原位置或只保存必要的分析记录。

清洗文本仍可能包含姓名、联系方式、私密经历和原作表达，不因去标签就匿名化。需要共享分析档案时另外确认可分享范围，移除不必要的实体与原句，保留方法和概括。默认报告与用户语料都不分发。
