# 提炼风格档案

目标是得到可用于新题材的风格说明，而非复制原作者的内容或身份。采用 24 维观察网格，把每个重要发现写成“规律 + 基线 + 样本”三层；证据不足的维度保留空缺。

## 1. 确定范围与保存方式

确认用户希望分析的样本、目标文体和可用权限。只处理用户提供或获准访问的材料，不因分析任务额外收集作者私人资料。

可以直接在对话中交付。需要保存时，采用用户工作区内的相对目录，例如 `style-profile/`，不要用真实姓名或账号命名目录。原件、清洗语料、摘录和报告留在用户工作区；不自动回写到本 Skill、安装目录或公开发布包。公开样本不等于允许整篇复制、重新分发。

建议的运行目录：

```text
style-profile/
  sources/             # 用户允许本地保存时才建立，原件保持不变
  corpus/              # 清洗后的分析副本
  _meta/               # 来源索引、处理口径与分析报告
  beat-sheets/          # 逐篇节拍表
  WRITING-DNA.md
  01-language-dna.md ... 06-style-controls.md
  outputs/             # 新稿与复核结果，按需保存
```

记录匿名样本 ID、来源定位、文体、日期范围、长度、采集与清洗方式、摘录和分享限制。无需填写真实作者姓名；用户提供的原件可以留在原位置，仅记录相对定位。

## 2. 评估覆盖范围

篇数、总字数、文体跨度、时间跨度、作者归属和编辑加工都会影响观察结果。单篇可以分析这篇的特点，不能直接代表作者全部风格；多篇也不自动构成“可靠”证明。不同系列、年代、合作者或平台差异明显时分组描述，不取平均掩盖差异。

没有固定的“几篇即可靠”门槛。逐条标明“多篇重复出现”“仅一处观察”“存在反例”或“样本不足”。无法确认归属时说明限制，不补造作者画像。

## 3. 保留原件，制作分析副本

按 [预处理规范](preprocess.md) 识别输入类型。原件用于检查标题层级、段落、加粗、图片等结构；清洗副本主要用于语言统计。口播意群分析是可选口径，默认保留原标点，不能将意群结果与自然句结果混为一谈。

## 4. 建立样本统计

选择保存报告时可运行：

```bash
python3 "<skill-dir>/scripts/distill_metrics.py" "style-profile/corpus" --out "style-profile/_meta/baseline-report.md" --json "style-profile/_meta/baseline-report.json"
```

命令在用户工作区执行，`<skill-dir>` 替换为本 Skill 的安装位置；输入和输出使用工作区相对路径。默认不输出原句与高频实体；只有权限和必要性明确时才加 `--include-samples`，并保持报告私有。

记录脚本版本、样本范围、字数与切分口径。句长、离散程度、短句比例、语气词、词组、标点和数字等指标只描述这组样本。脚本未计算的字段写“未测量”，人工估计须注明，不伪装成脚本结果。

指标不能检测是否由 AI 写作，不能证明质量或作者身份，也不是新稿必须达标的分数。某词在样本出现 0 次，只能说“本组未观察到”，不能推出禁用。题材、长度或处理口径不同，数值不能直接比较。

## 5. 用 24 维网格提炼语言

在 [语言模板](../templates/01-language-dna.md) 中完成以下维度。每一项记录观察规律、适用情境、变化或反例；有统计则写基线；样本层以匿名 ID 与位置定位为主，必要时才附获准的最小摘录。

| 组 | 维度 |
| --- | --- |
| A. 节奏与结构（6） | 句长分布、段落架构、开头方式、过渡方式、结尾方式、结构签名 |
| B. 词汇（6） | 词汇档位、术语处理、动词使用、修饰密度、代词策略、常用表达 |
| C. 语气（5） | 置信度、幽默、情绪温度、读者关系、正式度 |
| D. 修辞（4） | 类比隐喻、举证方式、重复手法、提问使用 |
| E. 表达机制（3） | 标点使用、排版习惯、强调方式 |

样本可按开头、过渡、举证、态度表达、代表性表达、结尾、节奏变化七种功能整理，无需每桶凑数。避免集中摘录足以替代原作的连续段落。没有摘录权限时，保留定位与手法概述即可；不要编一句“原文”填空。

## 6. 提炼结构、排版与观察视角

逐篇按 [节拍表模板](../templates/beat-sheet-example.md) 记录功能、长度、信息类型、过渡动作和情绪变化。先有逐篇证据，再归纳反复出现的原型；原型数量由样本决定，只有一种就写一种，无法归纳就保留逐篇描述。

将原型及选择条件填入 02。图文排版从原件读取后填入 03；纯文本缺少的排版信息标“无法观察”。把可迁移的提问和论证习惯填入 04，具体话题立场不升格成通用思维方式。

## 7. 分离内容与形式，形成写作动作

05 记录容易被误带到新稿里的独特案例、专有数据、标志性表达、经历、身份和具体结论。相同话题或公开事实并非自动不可用；新稿需要时重新核实来源、授权和论证，不能仅因原作出现过就全禁。

06 将有证据的风格观察转成带情境的写作建议。例如“长句多用于解释，关键动作后会停顿”，可以落实为“解释复杂关系时允许展开，落到动作时检查是否需要停顿”。不要把短句比例改成每几句的配额，不设普适禁词。只有用户明确选择的输出要求才作为硬约束，并标明它来自用户而非统计。

## 8. 检查与交付

填写入口 [WRITING-DNA.md](../templates/WRITING-DNA.md)，列出最有证据的特征、适用范围、局限和文件导航。模板中的待填项是运行时占位，不是已建立的风格规则。

检查三层是否闭合、24 维是否有状态、原型是否可回溯到节拍表、内容是否与形式分开、06 是否误把统计变成禁令。可用未参与提炼的获准样本复核；没有时说明未作留出检验。后续用新主题试写并按 [验证指南](verify-guide.md) 复核，仍不能把一次通过称为质量保证。
