# 按风格档案写新稿

用同一组形式手法处理新材料；原作者的话题、经历、数据、口头身份和结论不能自动进入新稿。

## 1. 读取适用档案

读取 `style-profile/WRITING-DNA.md`，确认样本范围、缺口和适用文体，再按本次任务读取 02 结构、01 语言与样本定位、06 风格控制、05 内容隔离。图文作品再读 03；需要选题与观察角度时读 04。

待填或证据不足的项不执行。档案与本次用户要求不一致时，遵守用户指定的文体、长度、语气和交付形式，并在复核中说明有意调整的维度。不要为了“像”而牺牲事实、可读性或用户目标。

## 2. 确定新主题与事实材料

明确读者、主题、用途、可采用的事实和用户希望保留的观点。缺少会改变结论的材料时，先补查或集中询问必要信息；其余部分可以继续。资料不足以支持目标篇幅时缩小范围，不用参考稿的故事补长度。

现实稿区分已核实事实、当事人自述、作者推断与未知；变化较快的信息按需刷新。没有真实经历就不能写亲测、在场、购买或成功运行。虚构任务按授权创造，但不要把参考作者的私人经历改名冒充用户亲历。

## 3. 选择结构并写节拍

按 02 中的适用条件选择原型，为新稿写功能序列与本次材料。可以删减、合并或调整节拍，不能先定结构再编事实填槽。样本没有可迁移原型时，只采用证据较强的局部手法，不硬造同款结构。

每一节检查它提供什么新信息、怎样接住上一节、读者接着会问什么。长度和情绪弧线服务内容；原稿数字只是描述，不是配额。

## 4. 应用语言、语气与排版

- 从 01 选择与本题相关的节奏、词汇档位、术语处理、代词、修辞和语气。学习动作与组织方式，句子重新写，不拼接摘录。
- 常用表达按真实语境使用，避免把辨识度变成口头禅重复。样本未出现的词不等于禁用，也不为凑相似度补语气词、短句、数字、夸张或自嘲。
- 依据 06 的“情境→写作动作”操作。定量偏差只提醒回读，不直接裁决；用户明确设定的限制单独执行。
- 排版来自 03 可观察结构，并适配实际发布环境。没有排版资料时采用本次任务合适的排版，不假称复刻了原作版式。
- 自称、署名、资历与经历只采用用户授权且真实的信息。替换账号名不能使原作者的经历变成用户经历；没有必要时用中性叙述。

## 5. 隔离内容并复核

对照 05，检查独特案例、专有数据、标志性句子、故事顺序和具体立场是否被无意迁移。需要用同一公开事实时重新确认来源；涉及原文引用时注明归属并限制到必要最小量，不能把近义改写当作原创论证。

按 06 做风格自检，再按 [验证指南](verify-guide.md) 比较原样本与新稿。确认哪些是有意调整、哪些是实际偏离，优先修复影响任务的差异。指标无需强制达标，也不能宣称“通过 AI 检测”。

## 6. 交付

默认交付用户要求的新稿，不附完整原文语料或私人档案。需要分析说明时简述采用的原型、关键调整、事实来源和复核方式。

仅在用户需要文件时保存到用户工作区，如 `style-profile/outputs/draft.md`；使用新的文件名或确认可覆盖，不自动发布或写回 Skill。新稿和验证报告也可能含私人材料，不能自动放进公开包。
