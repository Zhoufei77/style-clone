# 提炼流水线（distill）

目标：从 N 篇对标文案，产出「没读过原文的人，只看 DNA 也能写出同一个号的新一篇」的档案。
方法 = ghost-writer 的 24 维拆解网格 × ahao 的六层蒸馏。核心纪律：**蒸馏不是求平均，是建「规律 + 基线 + 样本」三层档案**。

## 语料门槛
- ≥ 5 篇才敢说「较可靠」；< 5 篇明确告诉用户这是「演示级」，不是可靠风格。
- 覆盖不同类型（观点/盘点/教程/短评…），结构原型库才全。

## 七步

### Step 1 建语料库
拷贝对标到 `<作者名>/raw/`，命名 `YYYY-MM-DD_类型_标题.md/txt`。原样保留（公众号保留 HTML 含加粗/图片）。

### Step 2 预处理（先有干净语料）
按 `references/preprocess.md` 清洗。**转录稿必须剥脚手架 + 意群归一**，否则基线失真。

### Step 3 跑量化基线（先有尺子，再谈风格）
```bash
python3 scripts/distill_metrics.py <作者名>/raw --out <作者名>/_meta/baseline-report.md
```
把关键数值原样填进 `01-language-dna.md` 的人味基线表：句长均值 + CV、短句(≤8字)占比、长句占比、语气词收尾率、高危词密度、名词化密度、排比三连密度、数字密度。**基线的意义是量化作者自然习惯，下游才知道草稿是「像作者」还是「往 AI 收敛」。**

### Step 4 语言肌理（24 维网格 × 三层）
用 ghost-writer 的 5 组 24 维当拆解网格，每一维都产出「规律(带区间) + 基线 + 样本(原文)」三层，写进 `01-language-dna.md`：

- **A 节奏结构（6 维）**：句长分布 / 段落架构 / 开头方式 / 过渡方式 / 结尾方式 / 结构签名
- **B 词汇（6 维）**：词汇档位 / 术语处理 / 动词能量 / 修饰密度 / 代词策略 / 口头禅
- **C 语气（5 维）**：置信度 / 幽默 / 情绪温度 / 与读者关系 / 正式度
- **D 修辞（4 维）**：类比隐喻 / 举证方式 / 重复手法 / 提问使用
- **E 机制（3 维）**：标点性格 / 排版习惯 / 强调方式

样本层尤其关键：按 **7 桶** 摘 30–50 条原文（开头 / 过渡 / 举证 / 表态吐槽 / 金句 / 结尾 / 节奏突变）。抽象规律留不住手感，原句留得住。

### Step 5 结构骨架（节拍级）
- 每篇抽 beat sheet（功能 / 字数 / 信息类型 / 过渡动作 / 情绪值），存 `beat-sheets/`。规范见 `templates/dna/beat-sheets/_example.md`。
- 聚成 3–5 个结构原型，写 `02-structure-dna.md`。
- 建开头库/结尾库（各附原文前两句/后两句）。
- 选题→结构决策树（什么样的选题用哪个原型）。

### Step 6 内容禁区（形式/内容分离）
把可迁移的「形式」留在各 DNA 文件；绑定话题的「内容」（话题/产品/数据/金句/立场/persona）写进 `05-forbidden-content.md`，供下游去重。

### Step 7 AI 味防火墙（最关键，不能省）
读 `templates/dna/06-ai-flavor-firewall.md`，把 Step 3–4 的描述性数值**翻成指令**：
- **A 硬禁用**：作者≈0 的高危词 → 红线禁用；偶尔用的 → 限流（注每篇上限）。
- **B 数值→硬指令**：把「短句 31%」翻成「每 3–4 句 1 句 ≤8 字」，「高危词 1.5/千字」翻成「全文 ≤5 个」。
- **C 反 AI 招式**：作者替代 signpost 的过渡/举证/动词前置/语气，各配 3–5 条原文。
- **D 自检清单**：下游写完逐条过。

⚠️ **判定铁律**：作者本来就爱用的词/句式不算 AI 味（如某作者把「首先/最后」当编号词用，就不能一刀切禁用）。基线的意义就是区分「作者习惯」和「AI 味」。

## 蒸馏质量自检
- 每条规律都带变化区间（不是单一均值）
- 01 有真实基线（来自脚本，不是拍的）
- 01 有 30–50 条原句样本，7 桶分好
- 06 建好：禁用具体到词、B 全是「每 N/≤X」可数指令、C 每条配样本
- 结构蒸到节拍级、归纳出原型
- 开头/结尾库附原文
- 05 列全禁区
- **终极验收：只看 DNA（不看原文），能否写出「同一个号新一篇」？**
