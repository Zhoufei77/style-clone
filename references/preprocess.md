# 预处理规范（蒸馏前必做）

量化基线脚本按「句号 / 换行」切句。对标文案的原始形态会污染基线，必须先清洗，否则句长 CV、短句占比、语气词率全部失真。

## 按输入类型识别与清洗

### 类型 A：口播 / 会议转录稿
特征：含「说话人 N 时间戳」「关键词：」「文字记录：」等转录标记。
- 剥掉：`说话人 N HH:MM:SS` 行、`关键词` 行、`文字记录` 行、日期/时长头、`> ` 引用头、`# ` 标题头。
- **把 `，；：！？` 归一成 `。`**——口播的节奏单位是「意群」，不是句号；不归一，脚本会把一整段当一句，句长基线全废。
- 说话人切点保留为空行（当段落分隔）。

### 类型 B：公众号 / 网页 HTML
- 剥 `<script>/<style>` 和标签，保正文与加粗/图片位置（排版 DNA 用）。
- 保留换行结构（段落）。

### 类型 C：Markdown
- 剥 `#` / `>` 标题与引用标记，保正文段落。标题字数若有信息可另存（排版 DNA 用）。

### 类型 D：纯文本
- 直接进，只统一编码、去多余空行。

## 通用步骤
1. UTF-8 读取，`errors='replace'`。
2. 去掉转录/平台脚手架（按类型 A/B/C）。
3. 意群标点归一（**仅转录稿需要**；公众号/纯文本保留原标点）。
4. 空行折叠（`\n{3,}` → `\n\n`）。

## 落地脚本
`scripts/preprocess.py` 自动识别类型并清洗：

```bash
python3 scripts/preprocess.py "<对标文件或目录>" --out "<作者名>/raw"
```

清洗后的 `.txt` 存进 `<作者名>/raw/`，再交给 `distill_metrics.py`。
